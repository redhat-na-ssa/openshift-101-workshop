== Attendee Accounts, Projects and Roles

Each attendee needs a user account and a project to deploy into.

Several steps act on the whole cluster and need cluster administrator rights: turning on user workload monitoring, installing Operators and the log collector's cluster roles, pruning images with `oc adm prune images`, and reading a node's configuration through `oc proxy`.
The custom metrics example in Scaling Applications works in the `default` project.

== Verification Checklist

Each attendee runs these before the workshop starts.

. Check that you are logged in to the cluster:
+
[source,bash,role=execute]
----
oc whoami
----
+
It prints your user name.

. Check that node metrics are available (expect a table of nodes):
+
[source,bash,role=execute]
----
oc adm top nodes
----

. Check that a default StorageClass exists (expect one class marked `(default)`):
+
[source,bash,role=execute]
----
oc get storageclass
----
