== Attendee Accounts, Projects and Roles

Each attendee needs a user account that can create projects (`oc new-project`).

Some steps need more than a project of your own:

* OpenShift vs Kubernetes creates a namespace with `oc create ns`, installs a project template in `openshift-config`, and reads the cluster network configuration.
* Networking runs a command inside the router in `openshift-ingress`.

== Network and Image Access

The cluster's nodes and the attendees' workstations reach:

* `github.com`, where the builds and the local build clone the retail store sample app from
* the registries that the sample app's `src/cart/Dockerfile` pulls its base images from
// TODO(Jason): name those registries.

Attendees' computers reach the cluster's API, its console, and its Routes under `*.apps.CLUSTER_NAME.BASE_DOMAIN`.

== Verification Checklist

Each attendee runs these before the workshop starts.

. Check that you are logged in to the cluster:
+
[source,bash,role=execute]
----
oc whoami
----
+
It prints your user name.

. Check that you can create a project (expect `yes`):
+
[source,bash,role=execute]
----
oc auth can-i create projectrequests
----

. Check that `podman` (or `docker`) and `helm` are installed:
+
[source,bash,role=execute]
----
podman --version
----
+
[source,bash,role=execute]
----
helm version
----
+
Each prints its version.
