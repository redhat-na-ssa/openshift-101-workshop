= Workshop Attendee Guide

== How the Workshop Works

Each workshop is a set of modules, one page each, and most pages end with a knowledge check: questions with the answer folded underneath.
You work with OpenShift in two ways, and the workshop environment gives you both:

* **A terminal for the command line**: the `oc` command-line tool, for managing your applications directly.
* **The web console**: a graphical interface to explore OpenShift projects, resources, and configurations.

Copy each command with the button on its code block.
Replace the values in capitals or quotes, such as `"NAMESPACE"` or `REPLACE_WITH_YOUR_TOKEN`, with your own before you run it.

Before you start, run the verification checklist at the end of your workshop's setup requirements, which the workshop's first page links to.

You don't have to install the command-line tools on your laptop: xref:cli-tools.adoc[Shared CLI tools] shows how to run them in a pod on the cluster.

== Where to Begin

If you are new to containers and Kubernetes, begin with xref:containers-for-vmware-admins:index.adoc[Containers and Kubernetes for VMware Admins].
Otherwise, begin with xref:openshift-fundamentals:index.adoc[OpenShift Fundamentals].
If your instructor has set a different order, follow theirs.
