= OpenShift 101 Workshop

This workshop is for developers, DevOps engineers and IT professionals who are getting started with OpenShift or want to sharpen their application development skills on it, and for infrastructure and VMware administrators who are new to containers.
By the end, you can build, deploy, expose, configure, scale and troubleshoot applications on OpenShift, from both the web console and the `oc` command line.
