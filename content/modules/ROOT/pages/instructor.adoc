= Workshop Instructor

This page is for the instructor who runs a delivery of the workshop.

== What the Workshop Covers

OpenShift Fundamentals and Running Applications are for developers, DevOps engineers and IT professionals who are getting started with OpenShift or want to sharpen their application development skills on it.
Containers and Kubernetes for VMware Admins is for infrastructure and VMware administrators who are new to containers, Kubernetes and OpenShift; it can run on its own, or as preparation for the other two.

Together, the workshops aim to:

. Explain the fundamentals of OpenShift and its core components.
. Show how to develop, containerize, and deploy applications efficiently.
. Explore best practices for application scaling.
. Give hands-on experience with troubleshooting and maintaining applications in an OpenShift environment.

== Environment and Requirements

Each workshop lists the cluster components, Operators, command-line tools, roles and access it needs on its own page.
Prepare everything for the workshops you deliver:

* xref:containers-for-vmware-admins:setup-requirements.adoc[Containers and Kubernetes for VMware Admins]
* xref:openshift-fundamentals:setup-requirements.adoc[OpenShift Fundamentals]
* xref:running-applications:setup-requirements.adoc[Running Applications]
// add-workshop.py adds workshops above this line

Every workshop needs:

* an OpenShift cluster, with a user account for each attendee
* a terminal with the `oc` command-line tool, matching the cluster version, for the command-line steps
* a current web browser, for the OpenShift web console

The workshop environment can provide the terminal and the web console side by side with the pages: `deploy/single-pod-values.yaml` in the repository holds the Helm values for running the site with a terminal and a console in Showroom.

== Before the Day

. Prepare the environment from the setup requirements above, for every attendee.
. Run the workshop end to end once on an environment built the same way.
. Send attendees the xref:attendee.adoc[Workshop attendee] page so they can check their workstation.

== Delivery Notes

=== Containers and Kubernetes for VMware Admins

The workshop is built for a virtual classroom: short talks, live demos, and Q&A at the end of every module.
The instructor runs every demo, and attendees with cluster access follow along in their own project.
Steps marked *Instructor only* need administrator rights or a Linux machine.
